# Akiii 回复器

Akiii 回复器是一款为 X / Twitter KOL 设计的 AI 回复辅助 Chrome 扩展。

它的核心目标很简单：  
帮你在浏览 X 推文时，快速生成自然、有观点、没有 AI 味的评论回复。

插件会根据推文内容自动生成短评，支持中文推文用中文回复，英文推文用英文回复。生成后的内容不会自动发送，而是先进入可编辑草稿窗口，方便你手动修改、润色，确认满意后再一键填入 X 回复框。

## 核心功能

### 1. 推文旁一键生成回复

在 X 时间线或推文详情页中，插件会在推文操作区域加入 `AI回` 按钮。

点击后，插件会自动识别当前推文内容，并生成一条适合直接回复的评论。

### 2. 回复框内一键填入

当你打开 X 回复窗口后，插件会显示 `AI填入` 按钮。

你可以直接生成回复内容，并将最终草稿填入 X 的回复框中。

### 3. 可编辑草稿窗口

为了解决 X 输入框自动填入后不方便修改的问题，Akiii 回复器不会直接强行发送内容。

生成后的回复会先进入一个独立的可编辑草稿窗口，你可以自由修改，确认后再点击 `填入 X`。

### 4. 中英文自动识别

插件会自动判断原推文语言：

- 中文推文 → 生成中文短评
- 英文推文 → 生成英文回复
- 中英混合 → 根据主要语言自动选择

英文回复会尽量保持自然、简洁、像真实 Web3 / Crypto KOL 的评论，而不是翻译腔。

### 5. 去 AI 味提示词

内置专门优化过的 KOL 回复提示词，默认追求：

- 短而有力
- 自然、不端着
- 有观点、有棱角
- 不写空话、套话、官话
- 避免“值得关注”“未来可期”“赋能生态”等 AI 味表达
- 默认不使用 emoji
- 不自动输出解释，只给最终回复

### 6. 支持禁用词

你可以在设置页配置禁用词。

比如：

```text
我觉得, 值得关注, 未来可期, 赋能, 生态

生成结果会尽量避开这些词，让回复更像真人表达。

7. 支持项目方 @账号

如果推文里出现项目方账号，插件可以在合适的位置自然带上项目方 @handle。

如果没有明确项目方账号，插件不会乱编。

8. 支持多种 API 接口

当前支持：

OpenAI Responses API
兼容 Chat Completions 的接口
API2D / 中转接口

如果 API Key 是 fk 开头，插件会自动识别为 API2D / 中转 Key，避免误走 OpenAI 官方接口导致报错。

9. 本地保存配置

API Key 和插件设置仅保存在浏览器本地扩展存储中，不会上传到任何第三方服务器。

10. 二次元高端 UI

Akiii 回复器 v1.9 加入了二次元初音风格底图，并采用半透明玻璃拟态 UI。

整体设计偏可爱、高级、轻量，适合长期挂在浏览器中使用。

使用场景

Akiii 回复器适合：

X / Twitter KOL 日常互动
Crypto / Web3 项目评论区回复
英文推文快速生成英文评论
中文推文快速生成短评

使用方式
下载插件文件并解压
打开 Chrome 浏览器
进入 chrome://extensions/
开启右上角「开发者模式」
点击「加载已解压的扩展程序」
选择插件文件夹
点击插件图标，填写 API Key 并保存
打开 X / Twitter 页面，刷新后即可使用
